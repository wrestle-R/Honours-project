# Lucent

An honours project exploring explainable chest X-ray analysis.

The frontend lives in this directory. Trained-model inference, FastAPI and evaluation results will be connected in a later phase.

## Local development

Use Node.js 22 or newer.

```sh
npm ci
npm run dev
```

## Checks

```sh
npm run typecheck
npm run build
```

Academic prototype. Not for clinical use.
